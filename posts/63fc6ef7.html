文生图模型介绍

文生图模型概述

AI 文生图（Text-to-Image）是一种利用人工智能技术，根据用户输入的自然语言描述自动生成图像的技术。用户只需要提供提示词（Prompt），模型就能够理解文本中的主体、场景、风格、构图和其他视觉元素，并生成符合描述的图片。近年来，随着深度学习和生成式人工智能技术的发展，文生图模型经历了从 GAN（生成对抗网络）、VAE（变分自编码器）到 Diffusion Model（扩散模型），再到 Diffusion Transformer（扩散 Transformer）的技术演进。目前，主流文生图模型主要采用扩散模型及其相关架构，通过逐步去噪或流匹配等方式，将随机噪声转换为符合文本描述的图像。按照模型来源、技术路线和商业模式，目前主流的文生图模型可以分为以下几类：

  • Stable Diffusion 系列：经典扩散模型，拥有成熟的开源生态。
  • FLUX 系列：新一代图像生成模型，注重图像质量和文本理解能力。
  • 国产开源模型：包括 Qwen-Image、Z-Image、Kolors 等，在中文理解和图像生成方面具有代表性。
  • 商业闭源模型：包括 Midjourney、GPT Image、Imagen 等，主要通过在线服务提供图像生成能力。
  • 其他开源模型：包括 PixArt、SANA、Hunyuan Image、AuraFlow 等，采用不同的技术路线。

文生图模型系列

Stable Diffusion 系列

Stable Diffusion 是由 Stability AI 推出的经典文生图模型系列，也是开源 AI 图像生成领域最具代表性的模型之一。Stable Diffusion 采用潜空间扩散模型（Latent Diffusion Model，LDM）技术，通过在压缩后的潜空间中执行扩散和去噪操作，降低图像生成过程中的计算开销。该系列模型拥有成熟的社区生态，支持大量第三方模型、LoRA、ControlNet 和其他扩展组件，在 AI 绘画、图片编辑、风格迁移等领域得到了广泛应用。

  • Stable Diffusion 3.5：采用更新的模型架构，在图像质量、文本理解和图像细节方面进一步改进。

FLUX 系列

FLUX 是 Black Forest Labs 推出的图像生成模型系列，是近年来非常有代表性的新一代文生图模型。FLUX 系列采用基于 Transformer 的生成架构，并结合流匹配（Flow Matching）等技术，在复杂提示词理解、图像细节、人物表现和文字渲染等方面具有较强的表现。与早期 Stable Diffusion 模型相比，FLUX 更加注重复杂场景的语义理解和高质量图像生成。

  • FLUX.1 [schnell]：侧重生成速度，适合快速图像生成场景。
  • FLUX.2：新一代模型系列，进一步拓展了图像生成和编辑能力。
  • FLUX Kontext：主要用于图像编辑，支持根据自然语言指令修改图像内容。

需要注意，FLUX 不同版本在模型权重开放程度和许可证方面存在差异。开放权重不代表可以不受限制地用于商业用途。

国产开源文生图模型

近年来，国产文生图模型发展迅速，涌现出 Qwen-Image、Z-Image、Kolors、Hunyuan Image 等具有代表性的模型。与早期主要以英文提示词为中心的文生图模型相比，部分国产模型更加注重中文语义理解、中文文字渲染和复杂指令执行能力。

Qwen-Image

Qwen-Image 是阿里巴巴推出的图像生成模型系列，具有较强的文本理解和图像生成能力，尤其值得关注的是其中文文字渲染能力。

Qwen-Image-Edit2025 年 8 月阿里巴巴支持通过自然语言指令进行图像编辑

主要特点：

  • 中文文字渲染：能够根据提示词生成包含中文文字的图片。
  • 复杂排版：适合海报、宣传图和包含文字的视觉设计。
  • 图像编辑：能够根据自然语言指令修改已有图片。

Z-Image

Z-Image 是阿里巴巴推出的图像生成模型系列，采用高效的生成架构，重点关注图像质量和推理效率之间的平衡。

模型名称发布时间开发机构主要特点

Z-Image-Turbo2025 年 11 月阿里巴巴侧重快速生成，适合低步数推理

主要特点：

  • 生成效率较高。
  • 注重图像质量与推理速度之间的平衡。
  • 适合本地图像生成和自动化图像创作场景。

文生图模型的选择与应用

不同文生图模型在图像质量、文本理解、文字渲染、生成速度和编辑能力方面各有侧重。实际选择时，可以根据应用场景进行判断。

应用场景值得关注的模型主要原因
AI 绘画与风格创作 Stable Diffusion 1.5、SDXL 社区生态成熟，拥有丰富的模型和扩展资源
高质量写实图片 FLUX.1 [dev]、FLUX.2、HiDream-I1 注重画面细节和整体视觉质量
中文文字渲染 Qwen-Image、CogView4 关注中文语义理解和文字排版
快速图像生成 FLUX.1 [schnell]、Z-Image-Turbo、Sana Sprint 采用高效推理方案
图片编辑 Qwen-Image-Edit、FLUX Kontext 支持通过自然语言指令修改图像
海报与商业设计 Ideogram、Recraft、Qwen-Image 适合文字排版和视觉设计
艺术创意设计 Midjourney、FLUX 注重艺术表现力和视觉效果
自动化图像生成 Stable Diffusion、FLUX、Qwen-Image 可以结合工作流引擎和 API 构建自动化服务

文生图模型的总结说明

目前，AI 文生图领域已经形成了较为丰富的模型生态，不同模型在生成质量、推理效率、中文理解、文字渲染和图像编辑等方面各有优势。从技术发展角度来看，Stable Diffusion 奠定了开源文生图生态的基础，FLUX 推动了新一代高质量图像生成技术的发展，而 Qwen-Image、Z-Image 等国产模型则进一步丰富了中文文生图和高效推理领域的技术选择。从应用角度来看：

  • Stable Diffusion：适合 AI 绘画、风格创作和需要丰富扩展生态的场景。
  • FLUX：适合追求高质量图像生成和复杂提示词理解的场景。
  • Qwen-Image：适合中文文字渲染、复杂排版和图像编辑场景。
  • Z-Image：适合关注图像生成效率的场景。
  • Midjourney、GPT Image、Imagen：适合希望直接使用成熟商业化图像生成服务的场景。

随着生成式人工智能技术不断发展，未来文生图模型将继续向更高的图像质量、更强的语义理解能力、更精准的文字渲染以及更加灵活的图像编辑能力发展。

ComfyUI 组成介绍

ComfyUI 不仅仅是一个 Web 可视化界面，它实际由以下两部分组成：

  • ComfyUI Frontend：提供基于 Web 的节点式交互界面。
  • ComfyUI Backend：负责模型加载、工作流执行和 AI 推理。

ComfyUI 典型工作流程：

ComfyUI 核心组件构成：

  • Load Checkpoint：加载 Stable Diffusion 模型。
  • CLIP Text Encode：将提示词编码为文本特征。
  • KSampler：执行扩散模型采样和图像生成。
  • VAE Decode：将潜空间数据解码为图片。
  • Save Image：保存生成的图片。

这些操作都由 ComfyUI 自己完成，不需要 Ollama 或 LM Studio 等第三方模型部署工具。官方文档也明确说明，ComfyUI 可以直接加载 Checkpoint、VAE、LoRA 等模型文件。

安装并启动应用

双击下载的 .exe 安装程序，按照安装向导完成安装。首次启动 Comfy Desktop 时，需要进行初始化配置：

  • (1) 选择运行方式，如果希望在本地计算机运行，选择 Local。
  • (2) 根据安装向导选择推荐配置，或者自行调整安装选项。
  • (3) 选择 ComfyUI 的安装目录。
  • (4) 等待程序自动下载 ComfyUI、Python 环境及相关依赖。
  • (5) 安装完成后，在 Dashboard 页面启动 ComfyUI 实例。

安装完成后，在 Comfy Desktop 的 Dashboard 页面启动本地 ComfyUI 实例，即可打开 ComfyUI 的 Web 操作界面，进行 AI 图像生成和工作流配置。

特别注意

  • Comfy Desktop 会自动管理本地运行环境，减少手动配置 Python 和依赖的工作。
  • Comfy Desktop 虽然是桌面应用程序，但 ComfyUI 的核心操作界面仍然是基于 Web 技术实现的。
  • Comfy Desktop 的硬件检测和 GPU 加速支持存在一定限制，不能认为所有显卡都能获得 GPU 加速。

安装 Portable 便携版

ComfyUI Portable 便携版是一个独立封装完整的 ComfyUI Windows 版本，内部已经整合了 ComfyUI 运行所需的独立的 Python (python_embeded)，只需要解压即可使用，适合希望快速部署并独立管理运行环境的用户。

选择安装包

如果选择 ComfyUI Portable 便携版，需要根据计算机使用的显卡型号和驱动环境选择对应的安装包。

ComfyUI 使用说明

注意事项

  • (1) ComfyUI 本身不包含完整的文生图模型，安装完成后仍需单独下载模型权重文件，并放到对应的模型目录中。
  • (2) 文生图模型通常需要较大的显存和系统内存，建议根据实际硬件配置选择合适的模型。
  • (3) 使用 NVIDIA 显卡时，应确保显卡驱动满足对应 CUDA 运行环境的要求。
  • (4) 使用 AMD 或 Intel 显卡时，需要确认具体 GPU 型号是否受到对应推理后端支持。
  • (5) 如果启动失败，优先检查显卡驱动、CUDA / ROCm / XPU 环境和依赖是否正确，而不是盲目重试。
  • (6) 多个 ComfyUI 实例可以配置共享模型目录，避免重复下载模型文件。

缺少显卡

如果计算机没有安装独立显卡，或者暂时不希望使用 GPU 推理，可以在启动 ComfyUI 时指定 --cpu 参数，让 ComfyUI 使用 CPU 执行模型推理。建议使用官方提供的 NVIDIA ComfyUI Portable 便携版，虽然安装包名称包含 NVIDIA，但该版本并非只能运行在 NVIDIA 显卡上，官方也支持通过 --cpu 参数进行 CPU 推理。

其中，--cpu 是 ComfyUI 提供的 CPU 推理启动参数，用于指定 CPU 作为计算设备，避免使用 GPU 执行模型推理。

ComfyUI 支持 CPU 推理

  • 无论计算机使用 Intel 还是 AMD 处理器（CPU），只要满足 ComfyUI 的运行环境要求，都可以通过 --cpu 参数使用 CPU 进行模型推理。
  • ComfyUI 同时支持 GPU 和 CPU 推理。CPU 推理不要求计算机配备独立显卡，但由于缺少 GPU 并行计算能力，图像生成速度通常会远远慢于 GPU 推理，具体差距取决于模型、CPU 性能及生成参数。
