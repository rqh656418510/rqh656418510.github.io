DeepSeek Harness 使用指南之一

发表于 2026-10-08 阅读次数： 评论数： 本文字数： 3.8k 阅读时长 ≈ 3 分钟

DeepSeek Harness 安装

Windows 平台

安装桌面端

Windows 平台可以直接从 DeepSeek Harness 官网 下载桌面端的 .exe 二进制可执行文件，然后双击 .exe 可执行文件，按照引导提示一步步安装即可。

Windows 平台的其他安装方式

  • Windows 平台除了可以直接安装 DeepSeek Harness 桌面端，还可以使用 npx 或源码构建方式进行安装，详细步骤可参阅下方 Linux 平台的安装步骤。
  • DeepSeek Harness 目前处于开发者预览阶段，桌面端安装包的版本和源码仓库可能使用不同的迭代版本。若桌面端与源码构建方式的界面或功能存在差异，应以所用版本自带的文档和实际界面为准。

Linux 平台

环境准备

确保系统已安装 Node.js（版本要求 >=24.9.0）以及 pnpm 包管理器。如果未安装 pnpm，可通过 npm install -g pnpm 安装。Linux 平台建议使用 fnm 管理 Node.js 版本，并使用普通用户安装 fnm，而不是使用 root 用户安装。

  • 安装 fnm
  • 安装 Node.js
  • 安装 pnpm

安装方式

在 Linux 平台上，DeepSeek Harness 的安装方式有多种，任意选择以下其中一种方式即可。

npx 一键快速安装

命令执行的操作：

  • npx 自动下载 @deepseek-ai/dsh 包
  • 启动 Web UI，浏览器会打开默认地址 http://127.0.0.1:3080

npx 使用说明

  • npx 首次启动 Web UI 时，会在 $DSH_HOME（Linux 平台的默认路径是 ~/.dsh）目录下，自动初始化 DeepSeek Harness 的配置目录。
  • 当浏览器可以正常打开 Web UI 界面，就说明 DeepSeek Harness 安装成功了；版本升级也很简单，重新执行上面这条 npx 命令，npx 就会拉取最新版本。
  • npx 是 npm 自带的命令，安装 Node.js 时通常会一起安装 npm，所以 npx 也就跟着有了。npx 的全称是 Node Package eXecute，作用是临时下载并运行一个 npm 包里的命令。
从源码构建并安装
  • 检查 GCC / G++ 是否已安装（构建 DSH 源码通常需要使用到 GCC / G++ 编译）
  • 若 GCC / G++ 编译器没有安装，则执行以下命令进行安装
  • 克隆仓库源码
  • 安装依赖并构建
  • 启动 Web UI，浏览器会打开默认地址 http://127.0.0.1:3080
  • 日后源码版本升级
  • 让 dsh 命令在任何 Shell 里都能直接用（包括非交互、脚本调用），无需 pnpm 命令前缀，比如 dsh web、dsh plugin add 命令都能直接使用（命令参数会原样透传），请自行将脚本里的 ~/deepseek-harness 更改为 DSH 的真实源码路径

DeepSeek Harness 的其他接入方式

  • DeepSeek Harness 除了可以使用 Web UI 之外，源码构建完成后还可以运行 dsh 命令进入全屏终端界面（TUI），比如执行 dsh --profile headless "你的指令" 命令进行无头模式（Headless Mode）运行。
Python SDK 安装

若希望程序化调用，还可以使用 DeepSeek Harness 官方提供的 Python SDK，通过 pip install deepseek-harness-sdk 安装，这里的安装内容包含匹配的原生运行时 wheel 与 dsh 命令。值得一提的是，Python SDK 运行不需要依赖系统级的 Node.js。

  • 安装 Python SDK（要求使用 Python 3.10 或更高版本）
  • 运行检测示例

脚本会打印最终 assistant 响应或所选 profile 提供的命令结果。所选 home 会保存生成的 sdk-minimal profile、已安装插件，以及 sessions/ 下的未压缩 JSONL 会话日志。检测示例与 SDK 绝不会静默读取 ~/.dsh。

  • 在 Python 程序中使用 SDK

Python SDK 会延迟启动内置的 dsh --profile sdk-minimal 进程，并复用到上下文管理器退出。Profile、其持久 patch、home patch 与任何有序 patches tuple 共同组成应用配置。不存在独立 Python 运行时 bin 或完整配置选项。

Python SDK 介绍

Python SDK 本质上是一个客户端封装，它通过打包一个内嵌的 Node.js 运行时来实现 "无需系统安装 Node.js" 的效果。具体来说，Python SDK 的安装包（wheel）中预置了一个单文件可执行程序 —— 该程序将 Node.js 运行时、Cordis 以及 DSH 的插件闭包打包在一起生成，因此目标机器上无需安装 Node.js 即可运行 DSH。Python 客户端负责启动这个可执行程序，并通过 JSON-RPC 协议与 DSH 通信。这个进程内部加载了一个 JSON-RPC 服务端插件（dsh-sdk-jsonrpc-server），在 stdio（stdin /stdout）上按行解析 JSON-RPC 消息。Python 客户端把请求写进子进程的 stdin，再从 stdout 读回响应和通知，双方就这样完成通信。

DeepSeek Harness 使用

DSH 基础使用

DeepSeek Harness 安装好只是第一步，还得按以下步骤让 Agent 接通模型并用起来：

  • (1) 申请 API Key：打开 https://platform.deepseek.com 注册登录 → 完成实名认证 → 进入 API Keys 创建密钥，复制以 sk- 开头的 Key（页面只显示一次，务必保存好）→ 账号充值少量余额。
  • (2) 启动 Web UI：终端执行 pnpm dsh web，浏览器打开 http://127.0.0.1:3080。
  • (3) 配置模型：进入 设置 → 模型，在 DeepSeek 卡片中粘贴 Key 并保存，然后选择需要使用的模型。
  • (4) 选择工作区：点击 选择工作区 → 添加目录，加入本地的项目文件夹，并点选它；否则输入框会保持灰色。
  • (5) 开始任务：输入任务，例如 “项目使用了什么技术栈”。

API 密钥说明

API 密钥是只写的，明文存放在 $DSH_HOME/.credentials.yaml 配置文件中，Web UI 界面只保留脱敏描述符，永远不会显示明文密钥，不用担心被截图泄露。

DSH 配置文件

  • DSH 的主目录是 $DSH_HOME，默认指向用户主目录下的 .dsh 文件夹（Linux 平台是 ~/.dsh，Windows 平台是 %USERPROFILE%\.dsh）。
  • DSH 的 “核心” 配置实际上是一个分层叠加的过程：底层是 DSH 自带的 cordis.yml，用户侧的 cordis.patch.yml 位于最关键的第二层，在其之上做配置的覆盖和补充。
  • DSH 的用户配置文件是 $DSH_HOME/profiles/<profile>/cordis.patch.yml，其中 <profile> 指配置目录名称，用于区分不同的运行时环境或使用场景，比如 web、headless、math-reasoning 等。
  • Cordis 是 DSH 框架的底层语言，*.patch.yml 文件是 Cordis 的补丁格式，用于在运行时动态合并多个配置层。这种设计让用户无需 Fork 代码，即可通过修改 cordis.patch.yml 改变整个系统的行为。

DSH 局域网访问

DSH 的 Web UI 默认只绑定 127.0.0.1，并且刻意禁用了 --host 0.0.0.0，因为 DSH Agent 具备执行本地命令的能力，一旦绑定到全网卡就等于把远程执行权限暴露给整个网段；同时它还有 Token 校验和 Host / Origin 信任校验两道限制，非回环访问会被拦截。所以局域网访问不了通常不是防火墙问题，而是出于安全考虑的设计限制，详细介绍可参考 官方文档。对于可信内网，有多种方法可以解决局域网访问的问题，比如手动配置（如下所示）和安装第三方插件；前提是 Web UI 所在的机器已经在防火墙中放行了 3080 端口。

  • Linux 平台编辑 ~/.dsh/profiles/web/cordis.patch.yml 配置文件（Windows 平台是 %USERPROFILE%\.dsh\profiles\web\cordis.patch.yml），添加以下配置内容，192.168.1.9 是运行 DSH 的那台机器在局域网中的 IP 地址
  • 正常执行 pnpm dsh web 命令，然后局域网内的浏览器就可以使用启动日志里带 Token 的那个 URL（比如 http://192.168.1.9:3080/?token=xxxx）访问 Web UI，这里的 192.168.1.9 是运行 DSH 的那台机器在局域网中的 IP 地址

DSH 实现局域网访问的第三方插件

  • dsh-anywhere-web：DeepSeek Harness Web 的任意入口访问增强插件。
  • dsh-web-lan-access：为 DeepSeek Harness Web UI 提供局域网 / 远程访问支持。
