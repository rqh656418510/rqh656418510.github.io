Ollama 本地部署 DeepSeek 模型

发表于 2025-03-19 更新于 2026-11-10 阅读次数： 评论数： 本文字数： 3.8k 阅读时长 ≈ 3 分钟

前言

本文将介绍本地如何使用 Ollama 部署 DeepSeek 模型，适用于 Windows、Linux、macOS、Docker 等运行环境。除了 DeepSeek 模型，同样适用于部署 Kimi、GLM、MiMo、Qwen、Llama、Gemma、Mistral 等主流开源模型。

macOS 平台说明

macOS 平台下安装和使用 Ollama 的步骤与 Linux 平台基本一致，本文不再赘述。

Ollama 使用

Ollama 使用说明

Ollama 安装完成后，各平台（Windows、Linux、macOS）的使用方式基本一致。

选择模型

在 Ollama 官网 上，搜索 Deepseek 模型，并选择本地能跑的模型版本。值得一提的是，个人电脑（显存 / 内存受限）通常只能部署量化后的蒸馏版本，比如 7B、32B 的本地量化版本。

使用模型

使用本地模型之前，请确保 Ollama 的后台服务已经运行起来。

命令行使用

模型下载完并成功部署后，就可以直接在终端或者 CMD 窗口中使用模型了，使用步骤如下：

  • (1) 执行以下命令启动模型
  • (2) 提出想要回答的问题（即输入提示词）

  • (3) 可以使用 /? 或者 /help 来获取 Ollama 的命令帮助手册

特别注意

在终端或者 CMD 窗口中，每次要使用模型，都需要先执行类似 ollama run deepseek-r1:7b 这样的命令，它的作用是在终端里提供一个交互式聊天界面。

客户端使用

本地部署好模型之后，如果觉得在命令行使用方式不太方便，可以继续通过一些第三方客户端（如 ChatBox、Cherry Studio）来使用模型。下面以 Cherry Studio 为例：

  • (1) 在 Cherry Studio 官网下载客户端应用并安装

  • (2) 运行 Cherry Studio，配置 Ollama 模型服务

  • (3) 添加模型，如果这里的模型列表里没有任何模型，则说明之前模型可能没有下载和部署好

  • (4) 选择所使用的模型

  • (5) 最后使用的界面效果

特别注意

通过第三方客户端（Cherry Studio）使用本地模型时，只需要提前启动 Ollama 后台服务即可，不需要执行类似 ollama run deepseek-r1:7b 这样的命令。原因在于：ollama run 只是一个命令行客户端，它的作用是在终端里提供交互式聊天界面并触发模型下载；而 Cherry Studio 是通过 Ollama 后台服务开放的本地 API（默认 http://127.0.0.1:11434）直接通信的。只要 Ollama 后台服务在运行、模型文件已存在于本地，Cherry Studio 就能按需让 Ollama 后台服务加载模型并完成推理，无须事先在终端里将模型跑起来。

Ollama 命令

模型运行命令

命令说明
ollama run qwen2.5:7b启动模型交互对话
ollama run qwen2.5:7b "你好"执行单次推理
ollama ps查看当前正在运行的模型
ollama stop qwen2.5:7b停止模型运行

模型管理命令

命令说明
ollama list查看本地已下载的模型
ollama pull qwen2.5:7b下载模型
ollama create qwen2.5:7b -f Modelfile根据 Modelfile 创建模型
ollama show qwen2.5:7b查看模型详细信息
ollama show qwen2.5:7b --modelfile查看模型对应的 Modelfile
ollama rm qwen2.5:7b删除模型
ollama cp qwen2.5:7b qwen2.5:7b-backup复制模型

服务管理命令

命令说明
ollama serve启动 Ollama Server
ollama --version查看 Ollama 版本
ollama help查看帮助信息
ollama help run查看指定命令的帮助信息

Ollama API 接口

Ollama 的默认服务地址：http://服务器IP:11434，常用 HTTP API 接口如下：

API 接口请求方式说明
/api/versionGET 查看 Ollama 版本
/api/tagsGET 查看本地模型列表
/api/showPOST 查看模型详细信息
/api/generatePOST 文本生成
/api/chatPOST 多轮对话
/api/embedPOST 生成文本向量
/api/psGET 查看正在运行的模型
/api/pullPOST 下载模型
/api/createPOST 创建模型
/api/deleteDELETE 删除模型
